# IMOBX.MD — MASTER PRODUCT & DEVELOPMENT SPECIFICATION

## 1. PROJECT OVERVIEW

Build **IMOBX.MD**, a modern real estate platform focused specifically on the **Republic of Moldova**.

IMOBX should not be just another real estate classifieds website.

The main concept is:

> **IMOBX helps people make better real estate decisions using property listings, market data, government statistics, calculators, comparisons, and verified official information.**

The platform should eventually cover the entire real estate lifecycle:

**Buy → Rent → Sell → Lease → Land → Build → Renovate → Invest → Compare → Verify**

### IMPORTANT

**Do NOT integrate AI/LLM functionality into the public website in V1.**

However, the entire architecture and database must be designed so that AI/ML can be added later without rebuilding the platform.

Build IMOBX as a **data-first real estate platform**, not as a simple classifieds clone.

The priority is:

**Clean UX → Reliable Data → Historical Data → Market Analytics → Calculators → Verification → Marketplace → ML → AI**
